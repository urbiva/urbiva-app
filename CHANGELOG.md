# Changelog

All notable changes to this repository. Dates are ISO 8601.

## [0.3.0] - 2026-11-10

### Added
- Urbiva Go: suitable and shortest route for three mobility profiles with segment-level trust.
- Urbiva Vision: photo to barrier report with AI estimate, human confirmation and manual fallback.
- Urbiva Urban: graph metrics, segment map, barrier review queue.
- Urbiva Impact: reachability simulation on a copy of the graph, before and after.
- Guided nine-step demo on the invented "Pilot zona A" network.
- CI for type checking, tests and production build.
